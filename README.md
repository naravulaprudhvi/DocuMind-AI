## 🌟 Executive Overview
**DocuMind AI** is an enterprise-ready, multi-tenant Document Intelligence platform powered by **Retrieval-Augmented Generation (RAG)**. It ingests complex PDF and Word (.docx, .doc) documents, parses both digital text and scanned pages via OCR fallback, segments content into semantically coherent overlapping chunks, indexes them into dense vector stores via FAISS, and provides an interactive conversational assistant.

Answers generated by DocuMind AI are **strictly grounded** in retrieved context chunks and include **fine-grained page-level citations** (`[Document: sample.pdf, Page 2]`) to eliminate hallucinations. The system features a modern ChatGPT-inspired web interface, in-browser Word and PDF document reader, multi-tenant document isolation, a 3-tier LRU caching architecture, local offline LLM support via Ollama, and an automated evaluation benchmarking suite.


## 🚀 Quick Start Guide

### 1. Prerequisites
- **Python 3.10+** (Tested on Python 3.11)
- **MySQL Server 8.0+** running locally or via Docker
- *(Optional)* **Tesseract OCR** (for scanned document processing)
- *(Optional)* **Ollama** (for local offline LLM generation)

### 2. Installation & Setup
```bash
# 1. Clone repository
git clone https://github.com/your-username/DocuMind-AI.git
cd DocuMind-AI

# 2. Create and activate Python virtual environment
python -m venv venv
venv\Scripts\activate       # Windows PowerShell / CMD
# source venv/bin/activate  # Linux / macOS

# 3. Install dependencies
pip install -r requirements.txt

# 4. Configure environment variables
cp .env.example .env
# Edit .env and enter your database credentials and API key

# 5. Run the Automated Test Suite (All 31 tests must pass)
pytest tests -q

# 6. Launch the Development Server
python app.py
```
Open your browser and navigate to: **`http://127.0.0.1:5000`**

## 🎯 Key Capabilities & User Workflows

### 1. Multi-Tenant Document Upload & In-Browser Viewer
- **Upload:** Upload multi-page PDFs and Word (.docx, .doc) files through `/documents`. Files are verified via magic byte signatures and isolated in user directories.
- **In-Browser Document Viewer:** Open and read Word documents and PDFs directly in the browser with rich formatting, headings, tables, print options, and raw downloads.
- **Inspect Chunks:** View extracted text chunks, character metrics, and run dense vector queries against individual documents in real time.

### 2. Multi-Document Conversational Chat
- **Document Selector:** Select single, multiple, or all documents simultaneously.
- **Grounded Answers:** Answers cite the exact document and page number (`[Document, Page X]`).
- **Source Snippets:** Expand interactive citation cards to view the exact text snippets and similarity scores.
- **Previous Documents Integration:** Seamless navigation between active chat conversation and the Document Knowledge Base.

### 3. Automated Executive Summarization
- One-click structured summaries for any uploaded document at `/documents/{id}/summary`.
- Calculates total word count, character count, estimated reading time, and 5 key executive takeaways.

### 4. 🛡️ Enterprise Data Security & Privacy Center
- **Strict Multi-Tenant Sandboxing:** User files and dense FAISS vector stores are physically isolated in dedicated user directories (`uploads/{user_id}/`). Cross-tenant access is blocked at the database and filesystem levels.
- **AI Privacy Shield (PII Masking):** Protects private personal data by scanning and redacting Credit Card numbers, SSNs, API keys, phone numbers, and emails before sending context to external AI providers.
- **Adversarial Prompt Injection Defense:** Context sanitizer neutralizes command injection tokens (`ignore previous instructions`, `role: system`, etc.) and enforces strict system instruction boundaries.
- **Cryptographic SHA-256 Checksums:** Calculates and logs cryptographic hash digests for uploaded documents to guarantee tamper-evident integrity.
- **HTTP Defense-in-Depth:** Modern security headers enforce Content-Security-Policy (CSP), anti-clickjacking (`X-Frame-Options: SAMEORIGIN`), MIME-sniff protection (`X-Content-Type-Options: nosniff`), and hardware access restrictions.
- **GDPR / CCPA Compliance Rights:**
  - *Data Portability:* Instant download of all user profile metadata, document catalogs, extracted chunks, and chat history as JSON (`/profile/export-data`).
  - *Right to be Forgotten:* Full cryptographic purge eradicating physical files from disk, vector indexes, caches, and database records upon password confirmation (`/profile/delete-account`).
- **Brute-Force Protection:** Rate-limiting lockout blocks repeated failed login attempts.
